Sample Benchmark Task: Interactive Product & Visual UI

An end-to-end demonstration of the exact deliverables required by Mercor: a realistic client brief, input asset package, reference standard, side-by-side AI critique, and scoring rubric.

Evaluation Task ID: AGY-EVAL-2026-04 Interactive Telemetry Dashboard & Responsive Web Component
Calibrated Standard: Senior Lead Frontend & Media Quality

Task Objective & Context

Client Scenario: A marine tech startup deploying autonomous aquaculture telemetry sensors needs a high-performance, responsive live monitoring widget to be embedded in their executive web portal.

  • Target Audience: Operations Directors and Field Biologists monitoring water parameters across multiple remote sites.
  • Single End Deliverable: A production-ready, accessible, standalone HTML/CSS/JS interactive dashboard widget.
  • Key Functionality: Real-time gauge visualization (DO, pH, Temp), status threshold alerts (Normal / Warning / Critical), and responsive reflow down to 320px viewport.

Strict Constraints & Failure Conditions

  • Strict Zero-External Dependency: No heavy external charting libraries (e.g. Highcharts/Chart.js); must be executed via semantic SVG and vanilla CSS/JS.
  • Accessibility Requirement: Strict WCAG 2.1 AA compliance (contrast ratio ≥ 4.5:1 for body copy; full ARIA live region support for metric updates).
  • Negative Constraint: No visual horizontal overflow at 375px width; no hallucinated CSS properties or deprecated layout modes (e.g. floats).
  • Performance Budget: Total payload < 25KB uncompressed, zero layout shifts (CLS < 0.05).

Input Files Supplied to Evaluator / Model

  • telemetry_sample.json: Raw unformatted stream data containing timestamps, DO (mg/L), pH values, water temperature (°C), and battery millivolts.
  • brand_tokens.css: Hex palette values (#0B0F19, #06B6D4, #10B981, #F43F5E), typographic scale (12px, 14px, 18px, 24px, 32px), border radii tokens.
  • status_matrix.pdf: Engineering specification sheet detailing exact warning and critical trigger thresholds for aquaculture organisms.

Evaluation Stress-Tests Embedded in Inputs

  • Missing Data Edge Case: Intermittent null values in sensor packet #142 to test graceful UI fallback vs. script crash.
  • Out-of-Range Spike: pH value of 11.2 (extreme anomaly) designed to test threshold indicator styling and alert badges.
  • Narrow Viewport String Lengths: Long localization labels ("Dissolved Oxygen Saturation Index") to test text truncation and flexbox wrap.
Senior Human Reference Deliverable (Shipped Standard) Craft Score: 10 / 10

Engineered with clean DOM hierarchy, fluid CSS grid, inline SVG circular gauges with dynamic dash-offset animations, complete ARIA labels, and graceful NaN handling.

  • Typographic Hierarchy: Clear contrast between metric title (14px uppercase), reading value (28px tabular mono), and units (12px muted).
  • Mobile Viewport: Wraps seamlessly into a stacked 1-column card at < 480px with no horizontal scrollbar.
  • Error Handling: Null sensor packet renders an amber dashed fallback state with a retry tooltip.
  • Craft Detail: Subtle micro-transitions on value updates with zero layout reflow.

  • Visual Flaw: Used absolute positioning on gauge labels causing severe text overlap on viewports under 600px.

  • Accessibility Breach: Light gray text on dark teal background produced a contrast ratio of 2.4:1 (fails WCAG AA threshold of 4.5:1).
  • Unhandled Exception: Null sensor packet threw unhandled TypeError: reading 'toFixed' of null, breaking the entire UI rendering.
